# Auswahl einer neuen Software für Mitgliederverwaltung

Zielgruppe: Turnverein Endingen e.V.

Mitglieder: 1000

Angebote 15

Mitgliedsbeitragsstruktur:
- Beitrag pro Person und Angebot, das "teuerste" Angebot bestimmt den Beitrag, alle anderen Angebote können damit wahrgenommen werden
- Ermäßigung je nach Anzahl Geschwisterkinder unter 18 Jahren (die auch Mitglied sein müssen)
